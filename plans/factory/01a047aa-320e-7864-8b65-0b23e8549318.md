# Build the todo API and React client end to end

## Intent

Bootstrap the empty Bun workspace in one vertical slice: a SQLite-backed
TypeScript todo HTTP API in `apps/server` and a React + Vite SPA in
`apps/web`, working end to end against each other. The slice ships colocated
unit tests for every route and the client layer, production builds for both
apps, and a narrated browser demo proving the locally deployed stack works.

  blocker (`DARK_FACTORY_S3_BUCKET` unset, no URL fabricated) on PR #3.
  Scope here is the issue body verbatim; the S3 honest-reporting rule stands

  than fabricating a URL.
- Sibling plan `plans/factory/01a0473c-37a3-76fd-be26-523a59a38f7d.md` is the
  committed contract for the same intake; this plan restands it for the
  current work item and is compatible with it.
- Ambiguity — "update (toggle/title)": implement `PATCH /todos/:id` accepting
  a non-empty `title`, a boolean `done`, or both; reject with 400 when the
  body carries neither supported field.
- Ambiguity — "CORS enabled for the web client origin": configurable
  `WEB_ORIGIN` defaulting to `http://localhost:5173` (the Vite dev origin),
  not a wildcard.
- `done` is stored as SQLite `INTEGER NOT NULL DEFAULT 0` but surfaced as a
  JSON boolean; `id` is a generated UUID text PK and `created_at` an ISO-8601
  timestamp.
- The SQLite file lives at `apps/server/data/todos.db` (gitignored); tests
  must use an isolated in-memory database so CI never writes it.

## Tasks

- [ ] Add `apps/server/package.json` + `tsconfig.json` with scripts `dev`
      (`bun --watch src/index.ts`), `start`, `test` (`bun test`), and `build`
      (`bun build --target=bun --outdir dist src/index.ts`).
- [ ] Add `apps/server/src/db.ts`: open `bun:sqlite` at
      `apps/server/data/todos.db` (path overridable for tests), create
      `todos(id TEXT PRIMARY KEY, title TEXT NOT NULL, done INTEGER NOT NULL
      DEFAULT 0, created_at TEXT NOT NULL)` on boot, and map rows to JSON
      with `done` as boolean.
- [ ] Add `apps/server/src/index.ts` serving on `PORT` (default 3000):
      `GET /health` → `{"status":"ok"}`; `GET /todos`, `GET /todos/:id`,
      `POST /todos`, `PATCH /todos/:id`, `DELETE /todos/:id`; 400 on invalid
      create/update payloads, 404 on unknown ids; `WEB_ORIGIN` CORS headers.
- [ ] Add colocated `apps/server/src/*.test.ts` (bun:test, in-memory db)
      covering health, list, get, create, title update, toggle, delete, CORS
      preflight/headers, malformed JSON, empty/invalid titles, unknown-id
      404s for get/patch/delete.
- [ ] Add `apps/web/package.json`, `vite.config.ts`, and TS config with
      scripts `dev`, `build` (`tsc && vite build`), `test` (`bun test`).
- [ ] Add `apps/web/src/api.ts` typed client on
      `import.meta.env.VITE_API_URL ?? "http://localhost:3000"` plus colocated

      API failures.
- [ ] Build `apps/web/src/App.tsx` + `src/main.tsx` + dark-theme CSS: list,
      add (non-empty validation), toggle done, delete, loading/error states;

- [ ] Extend root `.gitignore` for `apps/server/data/`, `dist/`, and

- [ ] Add paced `e2e/todo-full-stack.spec.ts` (Playwright) over deterministic

      verify, and publish `demo-artifacts/demo.mp4` per the narrated-demo

- [ ] Run both builds and `bach run group/ci`, then boot the built stack
      locally and verify the SPA performs full CRUD against the API.
